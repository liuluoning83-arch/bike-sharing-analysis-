# 共享单车租赁需求分析与预测

## 项目简介

本项目基于共享单车日租赁数据，完成数据清洗检查、探索性数据分析、机器学习建模与模型优化，目标是预测每天的共享单车总租赁量。

项目还扩展了小时级预测，可预测指定日期和小时的租赁量。

## 在线体验

可直接打开部署后的预测网页：

[共享单车租赁需求预测网页](https://citqbo6ityiglclmsukh68.streamlit.app/)

## 数据集

- 来源：Kaggle Rental Bike Sharing Dataset
- 主分析文件：`data/day.csv`
- 数据规模：731 条日级记录，16 个字段
- 时间范围：2011 年至 2012 年
- 预测目标：`cnt`，当天共享单车总租赁量

## 项目流程

1. 数据理解与质量检查
2. 探索性数据分析
3. 线性回归基线模型
4. 随机森林模型
5. 时间序列交叉验证与随机森林参数优化
6. 模型对比与结论总结

## 主要发现

- 日租赁量存在明显季节性，2012 年整体高于 2011 年。
- 工作日平均租赁量高于非工作日。
- 秋季平均租赁量最高，春季最低。
- 晴朗天气的平均租赁量最高，雨雪天气最低。
- 温度与租赁量呈中等偏强的正相关。
- 温度、体感温度和年份是预测租赁量的重要特征。

## 模型结果

| 模型 | MAE | RMSE | R² |
|---|---:|---:|---:|
| 线性回归 | 863.86 | 1166.02 | 0.613 |
| 默认随机森林 | 910.29 | 1112.20 | 0.648 |
| 优化后随机森林 | 891.26 | 1080.20 | 0.668 |

优化后的随机森林取得最低的 RMSE 和最高的 R²，因此被选为主模型。线性回归的 MAE 更低，说明不同指标对应不同的模型取舍。

## 小时级模型结果

小时级模型基于 `data/hour.csv` 的 17,379 条记录，额外加入 `hr`（小时）特征。训练集和测试集仍按时间先后划分。

| 模型 | MAE | RMSE | R² |
|---|---:|---:|---:|
| 线性回归 | 138.292 | 183.278 | 0.309 |
| 随机森林（基线） | **44.992** | **69.653** | **0.900** |
| 随机森林（调参后） | 45.257 | 69.782 | 0.900 |

调参后未优于基线模型，因此网页使用基线随机森林。小时是最重要特征，平均租赁量高峰出现在 8 时、17 时和 18 时。

## 本地运行

1. 安装依赖：

```bash
python -m pip install -r requirements.txt
```

2. 启动交互预测网页：

```bash
streamlit run app.py
```

网页根据日期、天气、温度、湿度和风速生成租赁量预测。模型仅使用 2011—2012 年数据训练，适合学习和演示，不能代替真实运营预测。

在网页侧边栏选择“小时级预测”后，还可输入 0—23 的小时值，得到该小时的预测租赁量。

## 批量预测

网页支持上传 CSV 文件，一次预测多条记录并下载结果。侧边栏选择日级或小时级预测后，下载的模板会自动匹配当前模式。

日级模板需要包含以下字段：

```text
date, weather, holiday, temperature_c, feels_like_c, humidity_percent, wind_speed_kmh
```

- `date`：日期，格式为 `YYYY-MM-DD`
- `weather`：天气，1=晴朗/少云，2=薄雾/多云，3=小雨或小雪，4=强降雨或强降雪
- `holiday`：是否节假日，0=否，1=是

小时级模板在上述字段基础上增加：

- `hour`：小时，取值为 0—23

## 模型可解释性

网页会展示随机森林的全局特征重要性，帮助使用者理解模型主要参考哪些输入变量。特征重要性描述的是模型的预测贡献，不代表变量之间的因果关系。

如需重新训练模型，请从 Kaggle 下载数据集，将 `day.csv` 放入 `data/` 文件夹后运行：

```bash
python -m src.train_model
```

如需重新训练小时级模型，请确保 `hour.csv` 位于 `data/` 文件夹后运行：

```bash
python -m src.train_hourly_model
```
